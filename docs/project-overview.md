# project-overview — 项目整体概述

## 一句话

把「AI 按 SKILL 文档现场操作 CorelDRAW 做吊牌」训练成「标准化自动化插件」：任何 agent 或编排系统提供配置（或模板+替换表），自动产出 双份 .cdr 源文件（原样+转曲）+ 印刷级 PDF + PNG 预览，全程 CMYK、X4/2020 双版本兼容。

## 背景与问题

用户经营电商仓储与服饰类目，吊牌/售后卡/标签类印刷物需求高频且重复：

- 传统流程：设计师在 CorelDRAW 手工排版 → 改文字 → 转曲 → 导出，每批次重复劳动
- 现有 AI 方案：AI 每次读文档现场写脚本，步骤多、有随机性、质量不稳定

## 方案：三层形态

| 层 | 形态 | 状态 |
|---|---|---|
| 引擎层 | CLI 工具（参数化生成器 + 模板填充器 + 登记器 + 自检） | ✅ 已验证 |
| 手册层 | Skill（SKILL.md + 21 条实测陷阱 + 训练规范） | ✅ |
| 插件层 | MCP Server（fastmcp 包装，任意 AI 客户端可调） | ⬜ 训练完成后 |

## 已验证能力（R1-R7 训练轮）

- COM 连接与 X4 版本确认（本机 build 14.0.0.701）
- 参数化生成：尺寸/颜色/打孔/文字，全 CMYK，越界防护（7/7 告警命中）
- **.cdr 程序化保存**：`SaveAs(path, StructSaveAsOptions{Version:1400})`（X4 格式）
- 真实模板分析：6 套 12 张吊牌全结构解析（异形/椭圆/矩形、PowerClip、孔位）
- 模板填充引擎：内容/规范化/#序号三模式匹配、中心恢复、越界自动缩放（10/10）
- 双 .cdr 输出：原样可编辑 + 全文转曲
- 坐标陷阱修复：PositionX/Y 参考点不固定 → 一律 LeftX/BottomY/RightX/TopY

## 业务价值

- 出活时间：单套吊牌从分钟级手工 → 一条命令 5-15 秒
- 质量：文字转曲 + CMYK 印刷规范 + 越界防护，减少返工
- 复用：模板入库一次，语义字段建档，之后"按名填值"无限复用
