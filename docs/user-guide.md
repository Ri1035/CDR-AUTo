# user-guide — 用户使用手册

> 面向使用者：无需阅读代码，按本手册操作即可。

## 1. 你需要准备什么

| 项 | 要求 |
|---|---|
| 电脑 | Windows 10/11，**保持登录的桌面**（自动化会真的打开 CorelDRAW 窗口画图） |
| 软件 | CorelDRAW Graphics Suite（X4 与 2020 已覆盖；X4 实测） |
| Python | 64 位 Python 3.11+（装一次 pywin32） |
| 使用方式 | 对 AI 说需求（WorkBuddy 等），或自己跑命令 |

## 2. 快速出牌：三步

### 第 1 步：说需求

对 AI 描述（口语即可，AI 会确认细节）：
> "做一批吊牌，50×90mm，白色底，正面要品牌名'XX'和价格，背面放洗涤说明，顶部打 4mm 孔。"

### 第 2 步：AI 生成配置并执行

AI 会生成配置文件并运行引擎，CorelDRAW 窗口会实时画出卡片（**这是正常现象，别关窗口**）。

### 第 3 步：验收产物

输出目录会得到：
- `名称_原样.cdr` —— 可编辑源文件（文字还能改）
- `名称_转曲.cdr` —— 文字已转曲（发印刷厂防跑样）
- `名称.pdf` —— 印刷级 PDF（CMYK、文字转曲）
- `名称_preview.png` —— 预览图

## 3. 用你自己的模板出活（推荐）

1. **模板入库**（每个模板做一次）：把模板 .cdr 给 AI，说"登记这个模板"。AI 会自动分析它的结构（几张卡、什么文字、孔在哪），生成档案。
2. **确认字段档案**：AI 会列出模板里的文字清单（如"品牌名""价格""洗涤说明"），请你确认/修改用途命名。
3. **出活**：之后只需说"用 XX 模板，品牌名改成 YY，价格改成 ZZ"，AI 自动完成替换 → 转曲 → 导出全套。

## 4. 常见问题

| 现象 | 说明 |
|---|---|
| CorelDRAW 窗口自己动了 | 正常——自动化是可视化操作，非后台运行 |
| 输出目录出现 `备份xxx.cdr` | CorelDRAW 自动备份功能生成，可删，不影响正本 |
| 想要 .cdr 源文件 | 自动输出两份（原样+转曲）；如需在 CorelDRAW 里再编辑，文档会保持打开可手动 Save As |
| 文字被缩小了 | 替换文字较长超出卡片时自动缩放防溢出——如需保持大字请缩短文字 |
| 换了台电脑还能用吗 | 能。拷贝整个项目文件夹 + 装好 CorelDRAW 和 Python 即可（详见 HANDOVER.md） |

## 5. 印刷交付说明

- PDF 已按印刷标准处理：CMYK 色彩、文字转曲
- 吊牌孔为挖洞示意（背景色圆），实际打孔由印刷厂后工序完成
- 如印刷厂要求 X4 版本源文件，转曲版即为通用交换格式
