# DESIGN — 视觉与印刷规范定义

> 本插件产出的所有印刷物遵循以下规范。改动规范须同步更新本文件并经用户确认。

## 1. 色彩

| 项 | 规范 |
|---|---|
| 色彩模式 | **全 CMYK**（`app.CreateCMYKColor(c, m, y, k)`），严禁 RGB 对象 |
| PDF 导出 | `PDFSettings.ColorMode = 1`（cdrPDFCMYK），`TextAsCurves = True` |
| 图片入卡 | 必须为 **CMYK 或灰度**；PowerClip（图框精准裁切）容器 |
| 吊牌孔表示 | 模板中孔对象 = 挖洞（背景色填充）；登记时记录实测尺寸 |

## 2. 字体

| 项 | 规范 |
|---|---|
| 中文 | Microsoft YaHei（微软雅黑） |
| 英文/数字 | Arial |
| 字号设置 | **必须** `Text.Story.Size`（磅）；`FontProperties.Size` 静默无效（陷阱 #3） |
| 字体核验 | 填充前用 `app.FontList`（实测 430+ 字体）核对目标字体存在，缺失即告警 |
| 安全字体 | 跨机清单制：首批 微软雅黑 / Arial / Noto Sans SC；模板定稿前逐字体核对 |

## 3. 尺寸与结构（实测体系）

| 项 | 规范 |
|---|---|
| 吊牌尺寸 | 常见 50×90 / 55×95 / 35×80mm（实测体系）；新尺寸走配置 |
| 卡片 | 直角矩形，无圆角；白底或指定底色 |
| 打孔 | 圆孔 **4mm**（水平居中）与条形孔 **12×2.5mm**；**孔位无统一常数——套模板时沿用模板已有孔对象，纯生成时由配置指定**（实测各套孔心距卡顶 3.75~15.27mm 不等） |
| 布局 | 画布中心放一套；多套可超出画布（PNG 导出含页外对象，PDF 用临时扩页法） |
| 套的定义 | 正反面都制作 = 单张；两张及以上为一套 |

## 4. 文件格式与版本

| 项 | 规范 |
|---|---|
| 源文件版本 | **X4（version 14）**——`SaveAs(path, StructSaveAsOptions{Version: 1400})`；兼容 2020 向下打开 |
| 文件本质 | X4+ 格式为 ZIP 容器（PK 头），内部 RIFF `vrsn` 块记录版本（X4=0x0578） |
| 保存限制 | `SaveAs` 需双参数（FileName + Options）经 `_oleobj_.Invoke` 传参；`Save()` 无参存回已打开文件 |
| 自动备份 | CorelDRAW 开启"保存时备份"→ 每次保存生成 `备份<原名>.cdr`——产物清单须过滤 |

## 5. 图层与注释

| 项 | 规范 |
|---|---|
| 生产内容 | 默认图层 |
| **注释/标注层** | 独立图层，建议命名 `NOTES`；枚举/替换/导出时跳过；印刷 PDF 不含注释层 |
| 老模板 | 注释混在生产对象里时，登记器列出疑似注释项由用户确认归属 |

## 6. 输出物标准（每套吊牌）

| 产物 | 标准 |
|---|---|
| `*_原样.cdr` | 可编辑源文件（文字未转曲），X4 格式 |
| `*_转曲.cdr` | 全文字转曲（ConvertToCurves），防换机跑样 |
| `*.pdf` | CMYK、文字转曲、印刷级 |
| `*_preview.png` | 预览（含画布外对象） |
| `result.json` | 机读结果（状态/产物/警告/日志） |
